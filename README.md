# 🛒 E-Commerce Web Application

A full-featured, modern E-Commerce web platform built using **Python (Django)**, **HTML5/CSS3**, **Bootstrap 5**, and **SQLite**. Designed with a sleek Dark Theme user interface and responsive layout for seamless online shopping.

---

## 🌟 Key Features

### 👤 User & Profile Management
- **User Authentication:** Registration, Login, Logout, and Secure Password Reset.
- **Dynamic Profile Page:** Users can update their personal information (email, phone number, address) and upload a profile picture.

### 🛍️ Product & Shopping Experience
- **Interactive Product Catalog:** View list of products with images, prices, and descriptions.
- **Dynamic Shopping Cart:** Add products, adjust quantities, or remove items dynamically.
- **Checkout Process:** Order summary and address entry for finalizing purchases.

### 📦 Order Tracking & Management
- **My Orders Section:** Track order statuses (`Pending`, `Completed`, `Cancelled`).
- **Interactive Order Cancellation:** Modal confirmation pop-up for order cancellations.
- **Admin Dashboard Integration:** Easily manage products, categories, and order statuses.

---

## 🛠️ Tech Stack

- **Backend:** Python 3, Django 6
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Database:** SQLite3
- **Version Control:** Git & GitHub
